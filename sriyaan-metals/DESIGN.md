# Sriyaan Metals — Premium Design System v2

## Creative direction

**Precision Atelier** — a cinematic industrial editorial experience with blackened steel, warm champagne metal, signal orange, oversized kinetic typography and measurement-inspired details. It must feel like an international metals partner, not a generic corporate template.

## Design-source synthesis

- **UI/UX Pro Max:** scroll-triggered storytelling, design-token discipline, contrast, focus and reduced-motion rules.
- **21st.dev:** split-screen animated hero composition, scroll progress, layered cards and concise conversion patterns.
- **Originkit:** cinematic framed imagery, optical glass overlays and depth-based image movement; adapted as original project code.
- **Animmaster:** slow scan-line, staged text reveal, image parallax and high-end timing principles; no paid source code copied.
- **Design Prompts:** Industrial + Modern Dark direction, asymmetric editorial layout and high-contrast typography.
- **Aura:** this reusable `DESIGN.md` token and component contract.
- **MotionSites:** motion-led hero narrative, visual chapters and CTA climax.

## Palette

- Ink `#071117` — primary blackened-steel canvas
- Carbon `#0B1920` — raised dark surfaces
- Steel `#102832` — technical panels
- Paper `#F1EFE8` — warm editorial canvas
- Fog `#E4E0D5` — light text
- Champagne `#CAA66A` — premium metal / trust / focus (`teal` legacy token)
- Champagne deep `#89642B` — accessible light-canvas label
- Signal orange `#FF7A1A` — primary conversion action only
- Muted `#8E969B` — supporting information

## Typography

- Display: Syne Variable 700; oversized uppercase, tight tracking, line-height .88–.94.
- Body/UI: Manrope Variable 400–700.
- Fallback technical display: Archivo Variable.
- Hero uses metallic gradient on one phrase only; body copy remains flat for readability.

## Layout

1240px content width, 1480px cinematic width. 80–120px desktop chapter rhythm. Asymmetric hero, technical 1px grids, square corners and deliberate negative space. Cards use subtle reflected-light sweep and measured elevation on hover.

## Signature interactions

1. Staged hero typography and image clip reveal.
2. Original WebGL light-bloom shader inspired by Originkit's Light Bloom concept.
3. Motion-powered 3D scroll showcase inspired by 21st.dev's hero-scroll pattern.
4. Fine-pointer image parallax with no functional dependency.
5. Slow optical scan beam over the product image.
6. Fixed 2px reading-progress line.
7. GSAP chapter reveals and restrained image movement.
8. Glass specification cards with strong contrast.

## Motion contract

450–1200ms entrance timing; only the hero uses a sequence. Hover feedback is 250–450ms. No autoplay audio, hijacked scroll, novelty cursor or animation that delays interaction. `prefers-reduced-motion` disables scan, marquee, GSAP entrances and smooth scrolling. Mobile keeps static depth and normal DOM reading order.

## Accessibility

WCAG 2.2 AA contrast, visible champagne focus, semantic landmarks/headings, persistent labels, aria-live form status, 44px targets, keyboard navigation and no color/motion-only meaning.

## Media policy

Current industrial imagery was newly generated for this new project and is representative. Replace with approved real product, factory, inspection, warehouse and packing photography before claims-based launch.
