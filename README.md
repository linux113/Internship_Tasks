# Internship_Tasks

This repository contains internship deliverables and two isolated web projects.

## SRIYAAN METALS (new)

Dynamic B2B metals website, product catalogue, enquiry system and protected admin CMS.

```bash
cd sriyaan-metals
npm install
npm run db:seed
npm run dev
```

See [`sriyaan-metals/README.md`](sriyaan-metals/README.md) for architecture, PostgreSQL migrations, environment variables, deployment, security controls and remaining client content.
